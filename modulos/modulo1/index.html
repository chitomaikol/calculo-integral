📖 Fundamentación Teórica

UTP CB215

Sea $f: [a, b] \to \mathbb{R}$ una función continua acotada. Se divide el intervalo $[a, b]$ en $n$ subintervalos de igual longitud mediante una partición regular:

$$\Delta x = \frac{b - a}{n}, \quad x_i = a + i \cdot \Delta x \quad (i = 0, 1, \dots, n)$$

En cada subintervalo $[x_{i-1}, x_i]$ se elige un punto muestra $x_i^*$. Dependiendo de la elección de dicho punto se definen:

Suma Izquierda: $$L_n = \sum_{i=0}^{n-1} f(x_i)\Delta x$$ Suma Derecha: $$R_n = \sum_{i=1}^{n} f(x_i)\Delta x$$ Punto Medio: $$M_n = \sum_{i=1}^{n} f(\bar{x}_i)\Delta x, \quad \bar{x}_i = \frac{x_{i-1} + x_i}{2}$$

Cuando el número de particiones tiende a infinito ($n \to \infty$ o $\Delta x \to 0$), la suma converge exactamente al valor de la integral definida:

$$\int_a^b f(x)\,dx = \lim_{n \to \infty} \sum_{i=1}^n f(x_i^*)\,\Delta x$$

📝 Ejercicios Resueltos del Taller

Ejercicio 1: $f(x) = x^2$ en $[0, 2]$ con $n = 4$ Sección 1.1
Paso 1 (Partición): $\Delta x = \frac{2 - 0}{4} = 0.5$.
Puntos de corte: $x_0 = 0.0,\, x_1 = 0.5,\, x_2 = 1.0,\, x_3 = 1.5,\, x_4 = 2.0$.
Paso 2 (Suma Izquierda):
$$L_4 = 0.5 [f(0) + f(0.5) + f(1.0) + f(1.5)] = 0.5 [0 + 0.25 + 1.0 + 2.25] = 0.5(3.5) = \mathbf{1.75}$$
Paso 3 (Suma Derecha):
$$R_4 = 0.5 [f(0.5) + f(1.0) + f(1.5) + f(2.0)] = 0.5 [0.25 + 1.0 + 2.25 + 4.0] = 0.5(7.5) = \mathbf{3.75}$$
Paso 4 (Punto Medio):
Puntos medios: $\bar{x} \in \{0.25, 0.75, 1.25, 1.75\}$.
$$M_4 = 0.5 [0.0625 + 0.5625 + 1.5625 + 3.0625] = 0.5(5.25) = \mathbf{2.625}$$
Paso 5 (Comparación con Integral Exacta):
$$\int_0^2 x^2 dx = \left[ \frac{x^3}{3} \right]_0^2 = \frac{8}{3} \approx 2.666667$$ Observamos que $L_4 < M_4 < \text{Exacto} < R_4$.
Ejercicio 2: $f(x) = \frac{1}{x}$ en $[1, 3]$ con $n = 5$ Sección 1.1
Paso 1 (Partición): $\Delta x = \frac{3 - 1}{5} = 0.4$.
Malla: $x = \{1.0,\, 1.4,\, 1.8,\, 2.2,\, 2.6,\, 3.0\}$.
Paso 2 (Evaluaciones):
$f(1.0) = 1.000,\, f(1.4) \approx 0.7143,\, f(1.8) \approx 0.5556,\, f(2.2) \approx 0.4545,\, f(2.6) \approx 0.3846,\, f(3.0) \approx 0.3333$.
Paso 3 (Aproximaciones):
$$L_5 = 0.4(1 + 0.7143 + 0.5556 + 0.4545 + 0.3846) = \mathbf{1.2436}$$ $$R_5 = 0.4(0.7143 + 0.5556 + 0.4545 + 0.3846 + 0.3333) = \mathbf{0.9770}$$ $$M_5 = 0.4(f(1.2)+f(1.6)+f(2.0)+f(2.4)+f(2.8)) = \mathbf{1.0919}$$
Paso 4 (Integral Exacta):
$$\int_1^3 \frac{1}{x} dx = \left[ \ln|x| \right]_1^3 = \ln(3) - \ln(1) = \ln(3) \approx \mathbf{1.098612}$$ ¡El punto medio $M_5$ presenta un error de apenas $0.61\%$!
