📖 Fundamentación Teórica Rigurosa

Álgebra y Cálculo Integral

Cualquier trinomio cuadrático de segundo grado $P(x) = ax^2 + bx + c$ ($a \neq 0$) puede transformarse en una suma o diferencia de cuadrados perfectos mediante la técnica de completación de cuadrados:

$$ax^2 + bx + c = a\left[ \left(x + \frac{b}{2a}\right)^2 + \frac{4ac - b^2}{4a^2} \right]$$

Si el integrando posee un numerador lineal de la forma $Ax + B$, se descompone estratégicamente para aislar la derivada exacta del trinomio $D'(x) = 2ax + b$:

$$Ax + B = \frac{A}{2a}(2ax + b) + \left( B - \frac{Ab}{2a} \right)$$ $$\int \frac{Ax + B}{\sqrt{ax^2 + bx + c}}\,dx = \frac{A}{2a}\int \frac{2ax + b}{\sqrt{ax^2 + bx + c}}\,dx + \left( B - \frac{Ab}{2a} \right)\int \frac{dx}{\sqrt{ax^2 + bx + c}}$$

⚙️ Protocolo de Desacoplamiento en Dos Etapas:

  1. Primera Integral (Potencia Inmediata): Sea $u = ax^2 + bx + c \implies du = (2ax + b)dx$. Se resuelve directamente como $\int u^{-1/2} du = 2\sqrt{u} = 2\sqrt{ax^2 + bx + c}$.
  2. Segunda Integral (Canónica Pura): Al completar el cuadrado en el radicando, se reduce a un arco seno si el coeficiente cuadrático es negativo ($a < 0$), o a una hiperbólica inversa / logaritmo si es positivo ($a > 0$).

📝 Ejercicios Resueltos Paso a Paso (Taller Oficial UTP)

Ejercicio 1: Numerador con Derivada Exacta del Radicando Taller XIII - Ej. 3
$$\int \frac{2x + 2}{\sqrt{x^2 + 2x - 3}}\,dx$$
Paso 1: Análisis de la derivada del radicando:
Sea $u = x^2 + 2x - 3$. Derivando: $$\frac{du}{dx} = 2x + 2 \implies du = (2x + 2)\,dx$$ Nótese que el numerador coincide exactamente con el diferencial del subradical.
Paso 2: Sustitución inmediata por regla de la potencia:
$$\int \frac{du}{\sqrt{u}} = \int u^{-1/2}\,du = \frac{u^{1/2}}{1/2} + C = 2\sqrt{u} + C$$
Paso 3: Retorno a la variable original:
$$2\sqrt{x^2 + 2x - 3} + C$$
Verificación por Derivación:
$$\frac{d}{dx}\left[ 2(x^2 + 2x - 3)^{1/2} \right] = 2 \cdot \frac{1}{2}(x^2 + 2x - 3)^{-1/2}(2x + 2) = \frac{2x + 2}{\sqrt{x^2 + 2x - 3}} \quad \checkmark$$
Ejercicio 2: Cuadrático Negativo que Conduce a Arco Seno Taller XIII - Ej. 2
$$\int \frac{x + 2}{\sqrt{4x - x^2}}\,dx$$
Paso 1: Ajuste del numerador respecto a la derivada $4 - 2x$:
Derivada de $4x - x^2$ es $4 - 2x = -(2x - 4)$. Descomponemos el numerador: $$x + 2 = -\frac{1}{2}(4 - 2x) + (2 + 2) = -\frac{1}{2}(4 - 2x) + 4$$
Paso 2: Separación en dos integrales:
$$I = -\frac{1}{2}\int \frac{4 - 2x}{\sqrt{4x - x^2}}\,dx + 4\int \frac{dx}{\sqrt{4x - x^2}}$$ - Parte 1: $-\frac{1}{2}\left(2\sqrt{4x - x^2}\right) = -\sqrt{4x - x^2}$.
- Parte 2: Completamos el cuadrado en el radicando: $$4x - x^2 = -(x^2 - 4x + 4 - 4) = 4 - (x - 2)^2 = 2^2 - (x - 2)^2$$ $$4\int \frac{dx}{\sqrt{2^2 - (x - 2)^2}} = 4\arcsin\left(\frac{x - 2}{2}\right)$$
Paso 3: Solución analítica consolidada:
$$-\sqrt{4x - x^2} + 4\arcsin\left(\frac{x - 2}{2}\right) + C$$
Verificación por Derivación:
$$\frac{d}{dx}\left[ -(4x - x^2)^{1/2} + 4\arcsin\left(\frac{x - 2}{2}\right) \right] = -\frac{4 - 2x}{2\sqrt{4x - x^2}} + \frac{4 \cdot (1/2)}{\sqrt{1 - \left(\frac{x-2}{2}\right)^2}} = \frac{x - 2 + 4}{\sqrt{4x - x^2}} = \frac{x + 2}{\sqrt{4x - x^2}} \quad \checkmark$$
Ejercicio 3: Trinomio Irreducible con Coeficiente Líder Taller XIII - Ej. 5
$$\int \frac{dx}{\sqrt{2x^2 + 2x + 5}}$$
Paso 1: Factorización del coeficiente cuadrático y completación:
$$2x^2 + 2x + 5 = 2\left( x^2 + x + \frac{5}{2} \right) = 2\left[ \left(x + \frac{1}{2}\right)^2 + \frac{5}{2} - \frac{1}{4} \right] = 2\left[ \left(x + \frac{1}{2}\right)^2 + \frac{9}{4} \right]$$
Paso 2: Extracción del factor $\sqrt{2}$ e integración canónica:
$$\int \frac{dx}{\sqrt{2}\sqrt{\left(x + \frac{1}{2}\right)^2 + \left(\frac{3}{2}\right)^2}} = \frac{1}{\sqrt{2}}\ln\left| \left(x + \frac{1}{2}\right) + \sqrt{\left(x + \frac{1}{2}\right)^2 + \frac{9}{4}} \right| + C$$
Paso 3: Expresión algebraica simplificada:
$$\frac{1}{\sqrt{2}}\ln\left| 2x + 1 + \sqrt{4x^2 + 4x + 10} \right| + C_1$$
Ejercicio 4: Fracción Compuesta con Coeficiente Cuadrático 9 Taller XIII - Ej. 1
$$\int \frac{2x + 3}{\sqrt{9x^2 - 12x + 8}}\,dx$$
Paso 1: Derivada de $9x^2 - 12x + 8$:
$$D'(x) = 18x - 12 \implies 2x + 3 = \frac{1}{9}(18x - 12) + \left(3 + \frac{12}{9}\right) = \frac{1}{9}(18x - 12) + \frac{13}{3}$$
Paso 2: Completación del cuadrado en $9x^2 - 12x + 8$:
$$9x^2 - 12x + 8 = (3x - 2)^2 + 4 = (3x - 2)^2 + 2^2$$
Paso 3: Solución analítica completa:
$$\frac{2}{9}\sqrt{9x^2 - 12x + 8} + \frac{13}{9}\ln\left| 3x - 2 + \sqrt{9x^2 - 12x + 8} \right| + C$$
