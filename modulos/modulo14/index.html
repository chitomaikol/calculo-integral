📖 Fundamentación Teórica Rigurosa

Cálculo Diferencial e Integral

El método de Integración por Partes es el análogo integral directo de la Regla de Leibniz para la derivada del producto de dos funciones diferenciables:

$$\frac{d}{dx}(u \cdot v) = u \frac{dv}{dx} + v \frac{du}{dx} \implies d(uv) = u\,dv + v\,du$$ $$\int u\,dv = u \cdot v - \int v\,du$$

Para optimizar la elección de $u$ (la función que se derivará para simplificar el integrando) y $dv$ (la expresión diferencial que se integrará con facilidad), se emplea la Regla Mnemotécnica LIATE (en estricto orden de prioridad descendente):

$$\begin{aligned} \mathbf{L} &\quad \longrightarrow \quad \text{Logarítmicas } (\ln x, \log_b x) \\ \mathbf{I} &\quad \longrightarrow \quad \text{Inversas Trigonométricas } (\arcsin x, \arctan x) \\ \mathbf{A} &\quad \longrightarrow \quad \text{Algebraicas / Polinómicas } (x^n, \sqrt{x}, P(x)) \\ \mathbf{T} &\quad \longrightarrow \quad \text{Trigonométricas } (\sin x, \cos x, \sec^2 x) \\ \mathbf{E} &\quad \longrightarrow \quad \text{Exponenciales } (e^x, a^x) \end{aligned}$$

🔄 Integrales Cíclicas y Despeje Algebraico:

Cuando se integran productos de funciones periódicas y exponenciales como $\int e^{ax}\cos(bx)\,dx$, tras aplicar partes dos veces consecutivas reaparece un múltiplo negativo de la integral original $I$. En lugar de continuar indefinidamente, se despeja $I$ algebraicamente: $(1 + k)I = \text{Términos Integrados} \implies I = \frac{\text{Términos Integrados}}{1 + k} + C$.

📝 Ejercicios Resueltos Paso a Paso (Taller Oficial UTP)

Ejercicio 1: Producto de Función Algebraica e Inversa Trigonométrica Taller XIV - Ej. 4
$$\int x \arctan x\,dx$$
Paso 1: Asignación LIATE:
La función Inversa trigonométrica ($\mathbf{I}$) tiene prioridad sobre la Algebraica ($\mathbf{A}$): $$u = \arctan x \implies du = \frac{1}{1 + x^2}\,dx$$ $$dv = x\,dx \implies v = \int x\,dx = \frac{x^2}{2}$$
Paso 2: Aplicación de la fórmula de partes:
$$\int x \arctan x\,dx = \left( \frac{x^2}{2} \right)\arctan x - \int \left( \frac{x^2}{2} \right)\left( \frac{1}{1 + x^2} \right)\,dx$$ $$= \frac{x^2}{2}\arctan x - \frac{1}{2}\int \frac{x^2}{1 + x^2}\,dx$$
Paso 3: Artificio algebraico para la segunda integral:
$$\frac{x^2}{1 + x^2} = \frac{x^2 + 1 - 1}{x^2 + 1} = 1 - \frac{1}{x^2 + 1}$$ $$\int \frac{x^2}{1 + x^2}\,dx = \int 1\,dx - \int \frac{dx}{x^2 + 1} = x - \arctan x$$
Paso 4: Consolidación y factorización:
$$\frac{x^2}{2}\arctan x - \frac{1}{2}(x - \arctan x) + C = \frac{x^2 + 1}{2}\arctan x - \frac{x}{2} + C$$
Verificación por Derivación:
$$\frac{d}{dx}\left[ \frac{x^2 + 1}{2}\arctan x - \frac{x}{2} \right] = \left( \frac{2x}{2}\arctan x + \frac{x^2 + 1}{2} \cdot \frac{1}{x^2 + 1} \right) - \frac{1}{2} = x\arctan x + \frac{1}{2} - \frac{1}{2} = x\arctan x \quad \checkmark$$
Ejercicio 2: Integral Cíclica Clásica Exponencial - Coseno Taller XIV - Ej. 1
$$I = \int e^{ax} \cos(bx)\,dx \quad (a^2 + b^2 \neq 0)$$
Paso 1: Primera integración por partes (LIATE: T antes de E):
$$u = \cos(bx) \implies du = -b\sin(bx)\,dx, \quad dv = e^{ax}\,dx \implies v = \frac{1}{a}e^{ax}$$ $$I = \frac{1}{a}e^{ax}\cos(bx) + \frac{b}{a}\int e^{ax}\sin(bx)\,dx$$
Paso 2: Segunda integración por partes sobre la integral residual:
$$u_2 = \sin(bx) \implies du_2 = b\cos(bx)\,dx, \quad dv_2 = e^{ax}\,dx \implies v_2 = \frac{1}{a}e^{ax}$$ $$\int e^{ax}\sin(bx)\,dx = \frac{1}{a}e^{ax}\sin(bx) - \frac{b}{a}\int e^{ax}\cos(bx)\,dx = \frac{1}{a}e^{ax}\sin(bx) - \frac{b}{a}I$$
Paso 3: Sustitución y despeje algebraico del ciclo:
$$I = \frac{1}{a}e^{ax}\cos(bx) + \frac{b}{a^2}e^{ax}\sin(bx) - \frac{b^2}{a^2}I$$ $$\left( 1 + \frac{b^2}{a^2} \right)I = \frac{e^{ax}(a\cos(bx) + b\sin(bx))}{a^2} \implies \left( \frac{a^2 + b^2}{a^2} \right)I = \frac{e^{ax}(a\cos(bx) + b\sin(bx))}{a^2}$$ $$I = \frac{e^{ax}\left( a\cos(bx) + b\sin(bx) \right)}{a^2 + b^2} + C$$
Ejercicio 3: Logaritmo de un Trinomio Cuadrático Taller XIV - Ej. 5
$$\int \ln(x^2 + 1)\,dx$$
Paso 1: Elección de partes con factor diferencial neutro $dv = dx$:
$$u = \ln(x^2 + 1) \implies du = \frac{2x}{x^2 + 1}\,dx$$ $$dv = dx \implies v = x$$
Paso 2: Desarrollo y división de polinomios:
$$\int \ln(x^2 + 1)\,dx = x\ln(x^2 + 1) - \int \frac{2x^2}{x^2 + 1}\,dx$$ Reescribiendo: $\frac{2x^2}{x^2 + 1} = 2 - \frac{2}{x^2 + 1}$. $$\int \left( 2 - \frac{2}{x^2 + 1} \right)\,dx = 2x - 2\arctan x$$
Paso 3: Solución analítica completa:
$$x\ln(x^2 + 1) - 2x + 2\arctan(x) + C$$
Verificación por Derivación:
$$\frac{d}{dx}\left[ x\ln(x^2+1) - 2x + 2\arctan x \right] = \ln(x^2+1) + \frac{2x^2}{x^2+1} - 2 + \frac{2}{x^2+1} = \ln(x^2+1) + \frac{2x^2+2}{x^2+1} - 2 = \ln(x^2+1) \quad \checkmark$$
Ejercicio 4: Función Compuesta Trascendente Seno-Logaritmo Taller XIV - Ej. 3
$$\int \sin(\ln x)\,dx$$
Paso 1: Cambio de variable exponencial previo:
Sea $x = e^t \implies dx = e^t\,dt$ y $t = \ln x$. La integral toma la forma cíclica estándar: $$\int e^t \sin(t)\,dt$$
Paso 2: Aplicación del resultado cíclico con $a = 1, b = 1$:
$$\int e^t \sin(t)\,dt = \frac{e^t(\sin t - \cos t)}{1^2 + 1^2} = \frac{e^t(\sin t - \cos t)}{2}$$
Paso 3: Retorno a la variable original $x$:
$$\frac{x\left( \sin(\ln x) - \cos(\ln x) \right)}{2} + C$$
