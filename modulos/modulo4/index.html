📖 Fundamentación Teórica

UTP CB215

En lugar de usar líneas rectas como el método de los trapecios, la Regla de Simpson (1/3) aproxima la curva mediante parábolas $P(x) = Ax^2 + Bx + C$ pasando por tres puntos sucesivos.

Condición Obligatoria de Paridad: Dado que cada parábola cubre 2 subintervalos contiguos, el número total de divisiones $n$ debe ser estrictamente un número par.

$$\Delta x = \frac{b - a}{n}, \quad n \in \{2, 4, 6, 8, \dots\}$$

La fórmula compuesta de Simpson asigna pesos periódicos $(1, 4, 2, 4, 2, \dots, 4, 1)$:

$$S_n = \frac{\Delta x}{3} \left[ f(x_0) + 4\sum_{i \text{ impar}} f(x_i) + 2\sum_{i \text{ par}} f(x_i) + f(x_n) \right]$$

Convergencia de Cuarto Orden y Exactitud Cúbica:
Si $f^{(4)}(x)$ es continua y $|f^{(4)}(x)| \le M$, la cota superior del error es:

$$|E_S| \le \frac{M (b - a)^5}{180 n^4}$$

Nótese que si $f(x)$ es un polinomio de grado $\le 3$, su cuarta derivada es idénticamente nula ($f^{(4)}(x) \equiv 0$), lo que significa que la Regla de Simpson calcula el valor exacto de la integral para funciones lineales, cuadráticas y cúbicas.

📝 Ejercicios Resueltos del Taller

Ejercicio 1: $\int_0^2 x^2 dx$ con Regla de Simpson ($n = 4$) Sección 1.4
Paso 1: $\Delta x = \frac{2 - 0}{4} = 0.5$. $n=4$ es par.
Puntos: $x_0 = 0.0,\, x_1 = 0.5,\, x_2 = 1.0,\, x_3 = 1.5,\, x_4 = 2.0$.
Paso 2: Evaluamos $f(x) = x^2$:
$f(0)=0.0$, $f(0.5)=0.25$, $f(1)=1.0$, $f(1.5)=2.25$, $f(2)=4.0$.
Paso 3: Aplicamos los coeficientes $(1, 4, 2, 4, 1)$:
$$S_4 = \frac{0.5}{3} \left[ 0 + 4(0.25 + 2.25) + 2(1.0) + 4.0 \right]$$ $$S_4 = \frac{1}{6} \left[ 0 + 4(2.5) + 2 + 4 \right] = \frac{1}{6} [10 + 6] = \frac{16}{6} = \frac{8}{3} \approx \mathbf{2.666667}$$
Paso 4 (Conclusión):
Como $f(x)=x^2$ tiene $f^{(4)}(x) = 0$, el error analítico es rigurosamente $0.000000$. Simpson entrega el valor exacto de la integral.
Ejercicio 2: $\int_1^3 \frac{1}{x} dx$ usando $S_4$ Sección 1.4
Paso 1: $\Delta x = \frac{3 - 1}{4} = 0.5$.
Nodos: $x_0=1.0,\, x_1=1.5,\, x_2=2.0,\, x_3=2.5,\, x_4=3.0$.
Paso 2: Evaluaciones fraccionarias exactas:
$f(1) = 1$, $f(1.5) = \frac{2}{3}$, $f(2) = \frac{1}{2}$, $f(2.5) = \frac{2}{5} = 0.4$, $f(3) = \frac{1}{3}$.
Paso 3: Sustitución en la fórmula ponderada:
$$S_4 = \frac{0.5}{3} \left[ 1 + 4\left(\frac{2}{3} + \frac{2}{5}\right) + 2\left(\frac{1}{2}\right) + \frac{1}{3} \right]$$ $$S_4 = \frac{1}{6} \left[ 1 + 4\left(\frac{16}{15}\right) + 1 + \frac{1}{3} \right] = \frac{1}{6} \left[ 2 + \frac{64}{15} + \frac{5}{15} \right] = \frac{1}{6} \left[ 2 + \frac{69}{15} \right]$$ $$S_4 = \frac{1}{6} [2 + 4.6] = \frac{6.6}{6} = \mathbf{1.100000}$$
Paso 4: Comparación con $\ln(3) \approx 1.098612$:
$$|E_S| = |1.098612 - 1.100000| = \mathbf{0.001388} \quad (\text{Error de apenas } 0.12\%)$$ Comprobamos empíricamente la superioridad de Simpson frente a Trapecio ($1.06\%$) y Punto Medio ($0.52\%$).
