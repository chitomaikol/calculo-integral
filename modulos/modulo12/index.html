📖 Fundamentación Teórica Rigurosa

Cálculo Diferencial e Integral

Las funciones hiperbólicas $\sinh(t) = \frac{e^t - e^{-t}}{2}$ y $\cosh(t) = \frac{e^t + e^{-t}}{2}$ cumplen la identidad fundamental $\cosh^2(t) - \sinh^2(t) = 1$. Mediante sustituciones hiperbólicas o relaciones logarítmicas directas, las cuadraturas con signos positivos bajo el radical se expresan rigurosamente como:

$$\begin{aligned} \int \frac{du}{\sqrt{u^2 + a^2}} &= \ln\left(u + \sqrt{u^2 + a^2}\right) + C = \text{arsinh}\left(\frac{u}{a}\right) + C_1 \\ \int \frac{du}{\sqrt{u^2 - a^2}} &= \ln\left|u + \sqrt{u^2 - a^2}\right| + C = \text{arcosh}\left(\frac{u}{a}\right) + C_1 \quad (|u| > a) \end{aligned}$$

Para expresiones sin radical en el denominador con diferencia de cuadrados, la descomposición en fracciones parciales conduce a la forma del área tangente hiperbólica:

$$\int \frac{du}{a^2 - u^2} = \frac{1}{2a}\ln\left|\frac{a + u}{a - u}\right| + C = \frac{1}{a}\text{artanh}\left(\frac{u}{a}\right) + C_1 \quad (|u| < a)$$

🏗️ Aplicación en Ingeniería: La Catenaria

El cable de una línea de transmisión suspendido entre dos torres adopta la curva $y = a\cosh(x/a)$. La longitud de arco y las tensiones estructurales se calculan resolviendo integrales de la forma $\int \sqrt{1 + (y')^2}dx = \int \cosh(x/a)dx = a\sinh(x/a)$.

📝 Ejercicios Resueltos Paso a Paso (Taller Oficial UTP)

Ejercicio 1: Radical Cuadrático Positivo Puro Taller XII - Ej. 1
$$\int \frac{dx}{\sqrt{x^2 + 16}}$$
Paso 1: Identificación del parámetro canónico:
Reconocemos la forma estándar $\int \frac{du}{\sqrt{u^2 + a^2}}$ donde $u = x$ y $a^2 = 16 \implies a = 4$.
Paso 2: Aplicación directa de la fórmula hiperbólica inversa / logarítmica:
$$\int \frac{dx}{\sqrt{x^2 + 4^2}} = \ln\left(x + \sqrt{x^2 + 16}\right) + C$$
Verificación por Derivación:
$$\frac{d}{dx}\left[ \ln\left(x + \sqrt{x^2 + 16}\right) \right] = \frac{1 + \frac{2x}{2\sqrt{x^2 + 16}}}{x + \sqrt{x^2 + 16}} = \frac{\frac{\sqrt{x^2 + 16} + x}{\sqrt{x^2 + 16}}}{x + \sqrt{x^2 + 16}} = \frac{1}{\sqrt{x^2 + 16}} \quad \checkmark$$
Ejercicio 2: Coeficiente Cuadrático Distinto de la Unidad Taller XII - Ej. 2
$$\int \frac{dx}{\sqrt{4x^2 - 25}}$$
Paso 1: Factorización o sustitución lineal previa:
Sea $u = 2x \implies u^2 = 4x^2$.
Diferenciando: $du = 2\,dx \implies dx = \frac{du}{2}$.
La constante es $a^2 = 25 \implies a = 5$.
Paso 2: Transformación e integración canónica:
$$\int \frac{\frac{du}{2}}{\sqrt{u^2 - 5^2}} = \frac{1}{2}\int \frac{du}{\sqrt{u^2 - 5^2}} = \frac{1}{2}\ln\left|u + \sqrt{u^2 - 25}\right| + C$$
Paso 3: Retorno a la variable original $x$:
$$\frac{1}{2}\ln\left|2x + \sqrt{4x^2 - 25}\right| + C$$
Verificación por Derivación:
$$\frac{d}{dx}\left[ \frac{1}{2}\ln|2x + \sqrt{4x^2 - 25}| \right] = \frac{1}{2} \cdot \frac{2 + \frac{8x}{2\sqrt{4x^2 - 25}}}{2x + \sqrt{4x^2 - 25}} = \frac{1}{\sqrt{4x^2 - 25}} \quad \checkmark$$
Ejercicio 3: Numerador Mixto Lineal y Radical Taller XII - Ej. 3
$$\int \frac{x + 2}{\sqrt{x^2 + 9}}\,dx$$
Paso 1: Separación de la suma en dos integrales independientes:
$$\int \frac{x + 2}{\sqrt{x^2 + 9}}\,dx = \int \frac{x}{\sqrt{x^2 + 9}}\,dx + 2\int \frac{dx}{\sqrt{x^2 + 9}}$$
Paso 2: Evaluación por métodos específicos:
- Término 1: Regla de potencia con $w = x^2 + 9 \implies dw = 2x\,dx$: $$\int \frac{x}{\sqrt{x^2 + 9}}\,dx = \frac{1}{2}\int w^{-1/2}\,dw = w^{1/2} = \sqrt{x^2 + 9}$$ - Término 2: Hiperbólica inversa estándar con $a = 3$: $$2\int \frac{dx}{\sqrt{x^2 + 3^2}} = 2\ln\left(x + \sqrt{x^2 + 9}\right)$$
Paso 3: Expresión consolidada final:
$$\sqrt{x^2 + 9} + 2\ln\left(x + \sqrt{x^2 + 9}\right) + C$$
Ejercicio 4: Forma Paramétrica General con Coeficientes Literales Taller XII - Ej. 4
$$\int \frac{dx}{\sqrt{b^2 x^2 - a^2}} \quad (b > 0, \, a > 0)$$
Paso 1: Sustitución de escala:
Sea $u = bx \implies du = b\,dx \implies dx = \frac{du}{b}$.
Paso 2: Integración inmediata:
$$\frac{1}{b}\int \frac{du}{\sqrt{u^2 - a^2}} = \frac{1}{b}\ln\left|u + \sqrt{u^2 - a^2}\right| + C = \frac{1}{b}\ln\left|bx + \sqrt{b^2 x^2 - a^2}\right| + C$$
