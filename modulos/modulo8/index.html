📖 Fundamentación Teórica Rigurosa

Análisis Matemático

La función exponencial natural $e^x$ es la única función matemática (salvo constantes multiplicativas) cuya tasa de cambio instantáneo es idéntica a su valor instantáneo, es decir $\frac{d}{dx}e^x = e^x$. Por el Teorema Fundamental del Cálculo:

$$\int e^u\,du = e^u + C$$

Para una función exponencial con base positiva arbitraria $a \in \mathbb{R}^+ \setminus \{1\}$, dado que $a^x = e^{x \ln a}$, su diferencial es $d(a^x) = a^x \ln a\,dx$, obteniendo la regla general de integración:

$$\int a^u\,du = \frac{a^u}{\ln a} + C \quad (a > 0, \, a \neq 1)$$

💡 Transformaciones Algebraicas Clave:

  • Multiplicación neutra de la unidad: Multiplicar numerador y denominador por $e^x$ para transformar denominadores de la forma $e^x + e^{-x}$ en $e^{2x} + 1 = (e^x)^2 + 1$.
  • Producto de potencias de igual exponente: Agrupar bases bajo un único exponente: $a^x \cdot b^x = (a \cdot b)^x$.
  • Expansión de binomios exponenciales: Desarrollar $(a^x \pm b^x)^2 = a^{2x} \pm 2(ab)^x + b^{2x}$ antes de integrar término a término.

📝 Ejercicios Resueltos Paso a Paso (Taller Oficial UTP)

Ejercicio 1: Combinación Lineal de Exponenciales Taller VIII - Ej. 4
$$\int (e^{2x} + 3e^x)\,dx$$
Paso 1: Aplicación de la linealidad del operador integral:
Separamos la suma en dos integrales independientes: $$\int (e^{2x} + 3e^x)\,dx = \int e^{2x}\,dx + 3\int e^x\,dx$$
Paso 2: Integración de cada término:
Para el primer término, hacemos la sustitución $u = 2x \implies du = 2\,dx \implies dx = \frac{du}{2}$: $$\int e^{2x}\,dx = \frac{1}{2}\int e^u\,du = \frac{1}{2}e^{2x}$$ Para el segundo término, la integral de $e^x$ es inmediata: $$3\int e^x\,dx = 3e^x$$
Paso 3: Resultado final consolidado:
$$\frac{1}{2}e^{2x} + 3e^x + C$$
Verificación por Derivación:
$$\frac{d}{dx}\left[ \frac{1}{2}e^{2x} + 3e^x + C \right] = \frac{1}{2}(2e^{2x}) + 3e^x = e^{2x} + 3e^x \quad \checkmark$$
Ejercicio 2: Producto de Exponenciales de Distinta Base Taller VIII - Ej. 3
$$\int 5^x e^x\,dx$$
Paso 1: Agrupación bajo una base común:
Aplicando la ley de los exponentes $a^x \cdot b^x = (ab)^x$: $$5^x \cdot e^x = (5e)^x$$ Nótese que la nueva base constante es $k = 5e \approx 13.5914 > 0$ y $k \neq 1$.
Paso 2: Integración con la fórmula general de base $a$:
$$\int (5e)^x\,dx = \frac{(5e)^x}{\ln(5e)} + C$$ Aplicando propiedades del logaritmo natural ($\ln(ab) = \ln a + \ln b$ y $\ln e = 1$): $$\ln(5e) = \ln 5 + \ln e = 1 + \ln 5$$
Paso 3: Solución analítica final:
$$\frac{5^x e^x}{1 + \ln 5} + C$$
Verificación por Derivación:
$$\frac{d}{dx}\left[ \frac{(5e)^x}{\ln(5e)} + C \right] = \frac{1}{\ln(5e)} \cdot (5e)^x \ln(5e) = (5e)^x = 5^x e^x \quad \checkmark$$
Ejercicio 3: Exponencial en Cociente (Tipo Arco Tangente) Taller VIII - Ej. 2
$$\int \frac{dx}{e^x + e^{-x}}$$
Paso 1: Multiplicación neutra por $\frac{e^x}{e^x}$:
$$\int \frac{dx}{e^x + e^{-x}} = \int \frac{e^x}{e^x(e^x + e^{-x})}\,dx = \int \frac{e^x}{e^{2x} + 1}\,dx = \int \frac{e^x}{(e^x)^2 + 1}\,dx$$
Paso 2: Sustitución elemental:
Sea $u = e^x \implies du = e^x\,dx$. Sustituyendo en la integral: $$\int \frac{du}{u^2 + 1} = \arctan(u) + C$$
Paso 3: Retorno a la variable independiente:
$$\arctan(e^x) + C$$
Verificación por Derivación:
$$\frac{d}{dx}\left[ \arctan(e^x) \right] = \frac{1}{1 + (e^x)^2} \cdot \frac{d}{dx}(e^x) = \frac{e^x}{e^{2x} + 1} = \frac{1}{e^x + e^{-x}} \quad \checkmark$$
Ejercicio 4: Cuadrado de Binomio con Bases Distintas Taller VIII - Ej. 5
$$\int (a^x - b^x)^2\,dx \quad (a, b > 0, \, a \neq 1, \, b \neq 1)$$
Paso 1: Expansión del binomio al cuadrado:
$$(a^x - b^x)^2 = (a^x)^2 - 2a^x b^x + (b^x)^2 = a^{2x} - 2(ab)^x + b^{2x}$$
Paso 2: Integración término a término:
$$\int a^{2x}\,dx - 2\int (ab)^x\,dx + \int b^{2x}\,dx$$ - Para $\int a^{2x}dx = \int (a^2)^x dx = \frac{a^{2x}}{\ln(a^2)} = \frac{a^{2x}}{2\ln a}$.
- Para $2\int (ab)^x dx = 2\frac{(ab)^x}{\ln(ab)} = \frac{2(ab)^x}{\ln a + \ln b}$.
- Para $\int b^{2x}dx = \frac{b^{2x}}{2\ln b}$.
Paso 3: Antiderivada general:
$$\frac{a^{2x}}{2\ln a} - \frac{2(ab)^x}{\ln(ab)} + \frac{b^{2x}}{2\ln b} + C$$
