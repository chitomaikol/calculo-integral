📖 Fundamentación Teórica

UTP CB215

La Regla del Trapecio aproxima el área bajo $f(x)$ uniendo los puntos adyacentes $(x_{i-1}, f(x_{i-1}))$ y $(x_i, f(x_i))$ mediante segmentos de recta secantes.

El área de cada trapecio elemental con base sobre el eje $x$ es:

$$A_i = \frac{f(x_{i-1}) + f(x_i)}{2} \Delta x, \quad \text{con } \Delta x = \frac{b - a}{n}$$

Al sumar los $n$ trapecios y factorizar $\frac{\Delta x}{2}$, observamos que los vértices interiores se comparten entre dos trapecios contiguos:

$$T_n = \frac{\Delta x}{2} \left[ f(x_0) + 2\sum_{i=1}^{n-1} f(x_i) + f(x_n) \right]$$

Cota Superior del Error: Si $f''(x)$ es continua y $|f''(x)| \le K$ en $[a, b]$, el error de truncamiento satisface:

$$|E_T| \le \frac{K (b - a)^3}{12 n^2}$$

📝 Ejercicios Resueltos del Taller

Ejercicio 1: $\int_0^2 x^2 dx$ con Regla del Trapecio ($n = 4$) Sección 1.2
Paso 1: $\Delta x = \frac{2 - 0}{4} = 0.5$. Malla: $x_0=0,\, x_1=0.5,\, x_2=1.0,\, x_3=1.5,\, x_4=2.0$.
Paso 2: Evaluamos las alturas correspondientes:
$f(0)=0$, $f(0.5)=0.25$, $f(1)=1.0$, $f(1.5)=2.25$, $f(2)=4.0$.
Paso 3: Aplicamos la fórmula del trapecio:
$$T_4 = \frac{0.5}{2} \left[ 0 + 2(0.25 + 1.0 + 2.25) + 4.0 \right]$$ $$T_4 = 0.25 \left[ 0 + 2(3.5) + 4.0 \right] = 0.25 [11.0] = \mathbf{2.750000}$$
Paso 4: Error frente al valor analítico:
$$\int_0^2 x^2 dx = \frac{8}{3} \approx 2.666667 \implies |E_T| = |2.666667 - 2.75| = \mathbf{0.083333}$$ Como $f''(x) = 2 > 0$ (cóncava hacia arriba), los trapecios quedan por encima de la curva y sobreestiman el área.
Ejercicio 2: $\int_1^3 \frac{1}{x} dx$ usando $T_5$ Sección 1.2
Paso 1: $\Delta x = \frac{3 - 1}{5} = 0.4$. Nodos: $x = \{1.0, 1.4, 1.8, 2.2, 2.6, 3.0\}$.
Paso 2: Valores funcionales:
$f(1.0)=1$, $f(1.4) \approx 0.714286$, $f(1.8) \approx 0.555556$, $f(2.2) \approx 0.454545$, $f(2.6) \approx 0.384615$, $f(3.0) \approx 0.333333$.
Paso 3: Suma ponderada:
$$T_5 = \frac{0.4}{2} \left[ 1 + 2(0.714286 + 0.555556 + 0.454545 + 0.384615) + 0.333333 \right]$$ $$T_5 = 0.2 \left[ 1 + 2(2.108998) + 0.333333 \right] = 0.2 [5.551329] \approx \mathbf{1.110266}$$
Paso 4: Comparación exacta:
$$\int_1^3 \frac{1}{x} dx = \ln(3) \approx 1.098612 \implies \text{Error} \approx \mathbf{0.011654} \ (1.06\%)$$
