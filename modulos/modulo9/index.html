📖 Fundamentación Teórica Rigurosa

Cálculo Diferencial e Integral

La regla de integración para potencias simples $\int x^n\,dx = \frac{x^{n+1}}{n+1} + C$ exhibe una singularidad analítica irreductible en el caso $n = -1$, pues provocaría una división por cero. La antiderivada de dicha potencia singular define la función logaritmo natural:

$$\int \frac{1}{u}\,du = \ln |u| + C$$

El uso riguroso del valor absoluto $|u|$ es indispensable para extender el dominio de la antiderivada a números reales negativos ($u \in \mathbb{R} \setminus \{0\}$), garantizando que $\frac{d}{du}\ln|u| = \frac{1}{u}$ para todo $u \neq 0$. Generalizando mediante la regla de la cadena para una función diferenciable $u = g(x)$:

$$\int \frac{g'(x)}{g(x)}\,dx = \ln |g(x)| + C$$

🧩 Descomposición de Fracciones Cuadráticas:

Cuando el integrando es una fracción racional $\frac{Ax + B}{ax^2 + bx + c}$ con trinomio irreducible en el denominador ($b^2 - 4ac < 0$), se separa el numerador en dos componentes: $$\frac{Ax + B}{ax^2 + bx + c} = k_1 \cdot \frac{2ax + b}{ax^2 + bx + c} + k_2 \cdot \frac{1}{a\left(x + \frac{b}{2a}\right)^2 + \Delta}$$ La primera parte genera directamente un logaritmo natural $\ln|ax^2 + bx + c|$, y la segunda genera un arco tangente.

📝 Ejercicios Resueltos Paso a Paso (Taller Oficial UTP)

Ejercicio 1: Cociente con Logaritmo en el Denominador Taller IX - Ej. 3
$$\int \frac{dx}{x \ln x}$$
Paso 1: Identificación de la sustitución $u = \ln x$:
Reescribimos algebraicamente el integrando separando la función y su diferencial: $$\int \frac{1}{\ln x} \cdot \left(\frac{1}{x}\,dx\right)$$ Sea $u = \ln x$. Su derivada es $\frac{du}{dx} = \frac{1}{x} \implies du = \frac{dx}{x}$.
Paso 2: Transformación directa e integración:
$$\int \frac{du}{u} = \ln |u| + C$$
Paso 3: Retorno a la variable original $x$:
$$\ln |\ln x| + C$$
Verificación por Derivación (Regla de la Cadena):
$$\frac{d}{dx}\left[ \ln|\ln x| + C \right] = \frac{1}{\ln x} \cdot \frac{d}{dx}(\ln x) = \frac{1}{\ln x} \cdot \frac{1}{x} = \frac{1}{x \ln x} \quad \checkmark$$
Ejercicio 2: Potencia Cuadrática del Logaritmo en Denominador Taller IX - Ej. 2
$$\int \frac{dx}{x (\ln x)^2}$$
Paso 1: Cambio de variable logarítmico:
Sea $u = \ln x \implies du = \frac{dx}{x}$. La integral se convierte en: $$\int \frac{1}{u^2}\,du = \int u^{-2}\,du$$
Paso 2: Aplicación de la regla de la potencia ($n = -2 \neq -1$):
$$\int u^{-2}\,du = \frac{u^{-2 + 1}}{-2 + 1} + C = -\frac{1}{u} + C$$
Paso 3: Antiderivada final:
$$-\frac{1}{\ln x} + C$$
Verificación por Derivación:
$$\frac{d}{dx}\left[ -(\ln x)^{-1} \right] = -(-1)(\ln x)^{-2} \cdot \frac{1}{x} = \frac{1}{x (\ln x)^2} \quad \checkmark$$
Ejercicio 3: Logaritmo bajo Radical Cuadrático Taller IX - Ej. 1
$$\int \frac{dx}{x \sqrt{4 - \ln^2 x}}$$
Paso 1: Sustitución de variable intermedia:
Sea $u = \ln x \implies du = \frac{dx}{x}$. Reemplazando: $$\int \frac{du}{\sqrt{4 - u^2}} = \int \frac{du}{\sqrt{2^2 - u^2}}$$
Paso 2: Integración mediante arco seno estándar ($\int \frac{du}{\sqrt{a^2 - u^2}} = \arcsin(u/a) + C$):
$$\arcsin\left(\frac{u}{2}\right) + C$$
Paso 3: Restitución de $u = \ln x$:
$$\arcsin\left(\frac{\ln x}{2}\right) + C$$
Verificación por Regla de la Cadena:
$$\frac{d}{dx}\left[ \arcsin\left(\frac{\ln x}{2}\right) \right] = \frac{1}{\sqrt{1 - \left(\frac{\ln x}{2}\right)^2}} \cdot \frac{1}{2x} = \frac{1}{\frac{\sqrt{4 - \ln^2 x}}{2}} \cdot \frac{1}{2x} = \frac{1}{x \sqrt{4 - \ln^2 x}} \quad \checkmark$$
Ejercicio 4: Fracción Racional Cuadrática Compuesta Taller IX - Ej. 4
$$\int \frac{x + 2}{2x^2 + 2x + 1}\,dx$$
Paso 1: Derivada del denominador y descomposición del numerador:
Sea $D(x) = 2x^2 + 2x + 1 \implies D'(x) = 4x + 2$.
Ajustamos el numerador $x + 2$ para extraer un múltiplo de $4x + 2$: $$x + 2 = \frac{1}{4}(4x + 2) + \left(2 - \frac{2}{4}\right) = \frac{1}{4}(4x + 2) + \frac{3}{2}$$
Paso 2: Separación en parte logarítmica y parte arcotangente:
$$I = \frac{1}{4}\int \frac{4x + 2}{2x^2 + 2x + 1}\,dx + \frac{3}{2}\int \frac{dx}{2\left(x^2 + x + \frac{1}{2}\right)}$$ - Para la parte 1: $\frac{1}{4}\ln(2x^2 + 2x + 1)$ (puesto que $2x^2 + 2x + 1 > 0$ $\forall x \in \mathbb{R}$).
- Para la parte 2, completamos cuadrados: $x^2 + x + \frac{1}{2} = \left(x + \frac{1}{2}\right)^2 + \frac{1}{4}$.
$$\frac{3}{4}\int \frac{dx}{\left(x + \frac{1}{2}\right)^2 + \left(\frac{1}{2}\right)^2} = \frac{3}{4} \cdot \frac{1}{1/2}\arctan\left(\frac{x + 1/2}{1/2}\right) = \frac{3}{2}\arctan(2x + 1)$$
Paso 3: Solución analítica completa:
$$\frac{1}{4}\ln(2x^2 + 2x + 1) + \frac{3}{2}\arctan(2x + 1) + C$$
