📖 Fundamentación Teórica Rigurosa

Cálculo Diferencial e Integral

El Método de Integración por Sustitución (o cambio de variable) representa la contraparte analítica directa de la Regla de la Cadena en derivación. Si $F$ es una antiderivada de $f$, entonces:

$$\int f(g(x)) \cdot g'(x)\,dx = \int f(u)\,du = F(u) + C = F(g(x)) + C$$

En el caso particular de funciones compuestas formadas por una base elevada a una potencia constante $n \in \mathbb{R}$ con $n \neq -1$, se aplica la Regla de la Potencia Generalizada:

$$\int [g(x)]^n \cdot g'(x)\,dx = \int u^n\,du = \frac{u^{n+1}}{n+1} + C \quad (n \neq -1)$$

⚙️ Protocolo de Resolución Sistemática:

  1. Elección del núcleo interno: Identificar la expresión $u = g(x)$ ubicada bajo un radical, exponente o denominador.
  2. Diferenciación exacta: Obtener $du = g'(x)\,dx$ y despejar o balancear las constantes que acompañan al diferencial.
  3. Conversión integral: Reexpresar la integral enteramente en términos de la variable auxiliar $u$ y aplicar $\int u^n du$.
  4. Retorno e invariancia: Restituir la variable original $x$ y verificar por derivación: $\frac{d}{dx}[F(g(x)) + C] = f(x)$.

📝 Ejercicios Resueltos Paso a Paso (Taller Oficial UTP)

Ejercicio 1: Integral con Radical en el Denominador Taller VII - Ej. 1
$$\int \frac{x^2}{\sqrt{x^3 + 2}}\,dx$$
Paso 1: Elección de la variable auxiliar $u$ y su diferencial:
Sea la expresión subradical $u = x^3 + 2$. Diferenciando ambos miembros: $$du = \frac{d}{dx}(x^3 + 2)\,dx = 3x^2\,dx \implies x^2\,dx = \frac{du}{3}$$
Paso 2: Transformación e integración por regla de la potencia:
$$\int \frac{x^2}{\sqrt{x^3 + 2}}\,dx = \int \frac{1}{\sqrt{u}} \cdot \frac{du}{3} = \frac{1}{3}\int u^{-1/2}\,du$$ $$\frac{1}{3} \cdot \left[ \frac{u^{-1/2 + 1}}{-\frac{1}{2} + 1} \right] + C = \frac{1}{3} \cdot \left[ \frac{u^{1/2}}{1/2} \right] + C = \frac{2}{3}u^{1/2} + C$$
Paso 3: Retorno a la variable original $x$:
$$\frac{2}{3}\sqrt{x^3 + 2} + C$$
Verificación por Derivación:
$$\frac{d}{dx}\left[ \frac{2}{3}(x^3 + 2)^{1/2} + C \right] = \frac{2}{3} \cdot \frac{1}{2}(x^3 + 2)^{-1/2} \cdot (3x^2) = \frac{x^2}{\sqrt{x^3 + 2}} \quad \checkmark$$
Ejercicio 2: Factor Lineal y Trinomio bajo Radical Taller VII - Ej. 5
$$\int (x + 3)\sqrt{x^2 + 6x}\,dx$$
Paso 1: Identificación y factorización del diferencial:
Sea $u = x^2 + 6x$. Derivando con respecto a $x$: $$du = (2x + 6)\,dx = 2(x + 3)\,dx \implies (x + 3)\,dx = \frac{du}{2}$$
Paso 2: Reemplazo algebraico e integración:
$$\int (x + 3)(x^2 + 6x)^{1/2}\,dx = \int u^{1/2} \cdot \frac{du}{2} = \frac{1}{2}\int u^{1/2}\,du$$ $$\frac{1}{2} \cdot \frac{u^{3/2}}{3/2} + C = \frac{1}{2} \cdot \frac{2}{3} u^{3/2} + C = \frac{1}{3}u^{3/2} + C$$
Paso 3: Expresión final en función de $x$:
$$\frac{1}{3}(x^2 + 6x)^{3/2} + C = \frac{1}{3}\sqrt{(x^2 + 6x)^3} + C$$
Verificación por Regla de la Cadena:
$$\frac{d}{dx}\left[ \frac{1}{3}(x^2 + 6x)^{3/2} \right] = \frac{1}{3} \cdot \frac{3}{2}(x^2 + 6x)^{1/2}(2x + 6) = (x + 3)\sqrt{x^2 + 6x} \quad \checkmark$$
Ejercicio 3: Sustitución con Despeje de Variable Residual Taller VII - Ej. 2
$$\int \frac{x - 2}{(1 - 2x)^4}\,dx$$
Paso 1: Cambio de variable lineal y despeje de $x$:
Sea $u = 1 - 2x \implies 2x = 1 - u \implies x = \frac{1 - u}{2}$.
Diferenciando: $du = -2\,dx \implies dx = -\frac{du}{2}$.
El numerador se transforma en: $$x - 2 = \frac{1 - u}{2} - 2 = \frac{1 - u - 4}{2} = -\frac{u + 3}{2}$$
Paso 2: Sustitución completa y separación de potencias:
$$\int \frac{-\frac{u + 3}{2}}{u^4} \left(-\frac{du}{2}\right) = \frac{1}{4} \int \frac{u + 3}{u^4}\,du = \frac{1}{4}\int \left( u^{-3} + 3u^{-4} \right)\,du$$ $$= \frac{1}{4}\left[ \frac{u^{-2}}{-2} + 3\left(\frac{u^{-3}}{-3}\right) \right] + C = \frac{1}{4}\left[ -\frac{1}{2u^2} - \frac{1}{u^3} \right] + C = -\frac{1}{8u^2} - \frac{1}{4u^3} + C$$
Paso 3: Retorno a $x$ y simplificación algebraica:
$$-\frac{1}{8(1 - 2x)^2} - \frac{1}{4(1 - 2x)^3} + C = -\frac{(1 - 2x) + 2}{8(1 - 2x)^3} + C = -\frac{3 - 2x}{8(1 - 2x)^3} + C$$
