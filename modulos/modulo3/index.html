📖 Fundamentación Teórica

UTP CB215

En la Regla del Punto Medio, la altura del rectángulo aproximante en el $i$-ésimo subintervalo $[x_{i-1}, x_i]$ se evalúa en el punto central:

$$\bar{x}_i = \frac{x_{i-1} + x_i}{2}, \quad \Delta x = \frac{b - a}{n}$$

La fórmula de cuadratura compuesta se expresa como:

$$M_n = \Delta x \sum_{i=1}^n f(\bar{x}_i) = \Delta x \left[ f(\bar{x}_1) + f(\bar{x}_2) + \dots + f(\bar{x}_n) \right]$$

Justificación Geométrica y Cota de Error:
La recta tangente trazada en $(\bar{x}_i, f(\bar{x}_i))$ produce un trapecio equivalente cuya área es idéntica a la del rectángulo de punto medio. Por ello, el error de aproximación satisface:

$$|E_M| \le \frac{K (b - a)^3}{24 n^2}$$

Nótese que el denominador es $24n^2$, lo que demuestra formalmente que la Regla del Punto Medio es típicamente el doble de precisa que la Regla del Trapecio para una misma cantidad de subintervalos.

📝 Ejercicios Resueltos del Taller

Ejercicio 1: $\int_0^2 x^2 dx$ con Regla del Punto Medio ($n = 4$) Sección 1.3
Paso 1: $\Delta x = \frac{2 - 0}{4} = 0.5$.
Subintervalos: $[0, 0.5]$, $[0.5, 1.0]$, $[1.0, 1.5]$, $[1.5, 2.0]$.
Paso 2 (Puntos Medios):
$\bar{x}_1 = 0.25$, $\bar{x}_2 = 0.75$, $\bar{x}_3 = 1.25$, $\bar{x}_4 = 1.75$.
Paso 3 (Evaluación Funcional):
$f(0.25) = (0.25)^2 = 0.0625$
$f(0.75) = (0.75)^2 = 0.5625$
$f(1.25) = (1.25)^2 = 1.5625$
$f(1.75) = (1.75)^2 = 3.0625$
Paso 4 (Cálculo de $M_4$):
$$M_4 = 0.5 [0.0625 + 0.5625 + 1.5625 + 3.0625] = 0.5 [5.2500] = \mathbf{2.625000}$$
Paso 5 (Análisis de Error):
$$\int_0^2 x^2 dx = \frac{8}{3} \approx 2.666667 \implies |E_M| = |2.666667 - 2.625| = \mathbf{0.041667}$$ Nótese que el error del trapecio fue $|E_T| = 0.083333$, cumpliéndose exactamente que $|E_M| = \frac{1}{2}|E_T|$.
Ejercicio 2: $\int_1^3 \frac{1}{x} dx$ usando $M_5$ Sección 1.3
Paso 1: $\Delta x = \frac{3 - 1}{5} = 0.4$.
Nodos de borde: $1.0, 1.4, 1.8, 2.2, 2.6, 3.0$.
Paso 2 (Puntos Medios):
$\bar{x} = \{1.2, 1.6, 2.0, 2.4, 2.8\}$.
Paso 3 (Evaluaciones):
$f(1.2) = 0.833333$, $f(1.6) = 0.625000$, $f(2.0) = 0.500000$, $f(2.4) = 0.416667$, $f(2.8) \approx 0.357143$.
Paso 4:
$$M_5 = 0.4 [0.833333 + 0.625000 + 0.500000 + 0.416667 + 0.357143] = 0.4 [2.732143] \approx \mathbf{1.092857}$$ Valor exacto: $\ln(3) \approx 1.098612 \implies \text{Error} \approx \mathbf{0.005755}$ ($0.52\%$).
