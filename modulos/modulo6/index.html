📖 Fundamentación Teórica

UTP CB215

Una función $F$ es una antiderivada o primitiva de $f$ en un intervalo $I$ si $F'(x) = f(x)$ para todo $x \in I$.

Si $F(x)$ es una antiderivada particular, la integral indefinida representa el conjunto infinito de todas las antiderivadas posibles:

$$\int f(x)\,dx = F(x) + C$$ donde $C \in \mathbb{R}$ es una constante arbitraria de integración que desplaza la curva verticalmente sin alterar sus pendientes tangenciales.

Fórmulas Básicas de Integración Inmediata:

$$\int x^n\,dx = \frac{x^{n+1}}{n + 1} + C \quad (n \neq -1)$$ $$\int \frac{1}{x}\,dx = \ln|x| + C$$ $$\int e^x\,dx = e^x + C$$ $$\int k\,f(x)\,dx = k \int f(x)\,dx \quad (k \in \mathbb{R})$$ $$\int \left[ f(x) \pm g(x) \right]\,dx = \int f(x)\,dx \pm \int g(x)\,dx$$

📝 3 Ejercicios Resueltos del Taller

Ejercicio 1: $\int (ax + by)^2 dx$ Sección 1.6 (Ej 1)
Paso 1 (Desarrollo del binomio al cuadrado):
$$(ax + by)^2 = a^2 x^2 + 2abxy + b^2 y^2$$
Paso 2 (Separación lineal con respecto a la variable $x$):
Notamos que la integración es respecto a la variable diferencial $dx$, por lo que $a, b, y$ actúan como constantes: $$\int (a^2 x^2 + 2abxy + b^2 y^2)\,dx = a^2 \int x^2\,dx + 2aby \int x\,dx + b^2 y^2 \int 1\,dx$$
Paso 3 (Aplicación de la regla de potencias):
$$= a^2 \left( \frac{x^3}{3} \right) + 2aby \left( \frac{x^2}{2} \right) + b^2 y^2 (x) + C$$ $$\mathbf{= \frac{a^2 x^3}{3} + abx^2 y + b^2 x y^2 + C}$$
Paso 4 (Verificación por Derivación):
$$\frac{d}{dx}\left[ \frac{a^2 x^3}{3} + abx^2 y + b^2 x y^2 + C \right] = a^2 x^2 + 2abxy + b^2 y^2 = (ax + by)^2 \quad \checkmark$$
Ejercicio 2: $\int \left( \frac{3}{x^2} - \frac{9}{\sqrt{x}} \right) dx$ Sección 1.6 (Ej 2)
Paso 1 (Reescritura con exponentes reales):
$$\frac{3}{x^2} = 3x^{-2}, \quad \frac{9}{\sqrt{x}} = 9x^{-1/2}$$ $$\int \left( 3x^{-2} - 9x^{-1/2} \right)\,dx$$
Paso 2 (Integración directa término a término):
$$= 3 \left( \frac{x^{-2 + 1}}{-2 + 1} \right) - 9 \left( \frac{x^{-1/2 + 1}}{-1/2 + 1} \right) + C$$ $$= 3 \left( \frac{x^{-1}}{-1} \right) - 9 \left( \frac{x^{1/2}}{1/2} \right) + C$$ $$\mathbf{= -\frac{3}{x} - 18\sqrt{x} + C}$$
Paso 3 (Verificación por Derivación):
$$\frac{d}{dx}\left[ -3x^{-1} - 18x^{1/2} + C \right] = 3x^{-2} - 18\left(\frac{1}{2}\right)x^{-1/2} = \frac{3}{x^2} - \frac{9}{\sqrt{x}} \quad \checkmark$$
Ejercicio 3: $\int (x - 1)(x + 1)\,dx$ Sección 1.6 (Ej 5)
Paso 1 (Diferencia de cuadrados):
$$(x - 1)(x + 1) = x^2 - 1$$
Paso 2 (Integración directa):
$$\int (x^2 - 1)\,dx = \int x^2\,dx - \int 1\,dx = \mathbf{\frac{x^3}{3} - x + C}$$
Paso 3 (Verificación por Derivación):
$$\frac{d}{dx}\left[ \frac{x^3}{3} - x + C \right] = x^2 - 1 = (x - 1)(x + 1) \quad \checkmark$$
