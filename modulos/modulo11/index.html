📖 Fundamentación Teórica Rigurosa

Cálculo Diferencial e Integral

Las derivadas de las funciones trigonométricas inversas producen expresiones algebraicas puras racionales y con radicales cuadráticos. Invirtiendo estos operadores obtenemos las formas canónicas inversas fundamentales:

$$\begin{aligned} \int \frac{du}{\sqrt{1 - u^2}} &= \arcsin(u) + C & \int \frac{du}{1 + u^2} &= \arctan(u) + C \\ \int \frac{du}{\sqrt{a^2 - u^2}} &= \arcsin\left(\frac{u}{a}\right) + C & \int \frac{du}{a^2 + u^2} &= \frac{1}{a}\arctan\left(\frac{u}{a}\right) + C \quad (a > 0) \end{aligned}$$

Cuando el integrando presenta un binomio lineal en el numerador $Ax + B$ sobre una forma cuadrática canónica, se aplica el método de descomposición aditiva:

$$\int \frac{Ax + B}{x^2 + a^2}\,dx = \frac{A}{2}\int \frac{2x}{x^2 + a^2}\,dx + B\int \frac{dx}{x^2 + a^2} = \frac{A}{2}\ln(x^2 + a^2) + \frac{B}{a}\arctan\left(\frac{x}{a}\right) + C$$

📐 Técnicas de Reconocimiento y Reducción:

  • Exponenciales con exponente par: Reconocer $e^{4x} = (e^{2x})^2$ con diferencial $2e^{2x}dx$, conduciendo directamente a una arcotangente en $u = e^{2x}$.
  • Factores trigonométricos cuadráticos: En $\int \frac{\sec^2 x}{\sqrt{1 - 4\tan^2 x}}dx$, notar que $d(2\tan x) = 2\sec^2 x dx$, reduciéndose a $\frac{1}{2}\arcsin(2\tan x)$.
  • Radicales con logaritmo al cuadrado: Expresiones como $\frac{1}{x\sqrt{a^2 - b^2\ln^2 x}}$ se reducen con $u = b\ln x$ y $du = \frac{b}{x}dx$.

📝 Ejercicios Resueltos Paso a Paso (Taller Oficial UTP)

Ejercicio 1: Numerador Compuesto sobre Radical Canónico Taller XI - Ej. 1
$$\int \frac{3 + x}{\sqrt{1 - x^2}}\,dx$$
Paso 1: Descomposición en dos integrales elementales:
$$\int \frac{3 + x}{\sqrt{1 - x^2}}\,dx = 3\int \frac{dx}{\sqrt{1 - x^2}} + \int \frac{x}{\sqrt{1 - x^2}}\,dx$$
Paso 2: Resolución individual de cada término:
- Para el primer término: integral inmediata de arco seno: $$3\int \frac{dx}{\sqrt{1 - x^2}} = 3\arcsin(x)$$ - Para el segundo término: sustitución por regla de potencias con $w = 1 - x^2 \implies dw = -2x\,dx \implies x\,dx = -\frac{dw}{2}$: $$\int \frac{x}{\sqrt{1 - x^2}}\,dx = -\frac{1}{2}\int w^{-1/2}\,dw = -\frac{1}{2}\left( \frac{w^{1/2}}{1/2} \right) = -w^{1/2} = -\sqrt{1 - x^2}$$
Paso 3: Consolidación del resultado:
$$3\arcsin(x) - \sqrt{1 - x^2} + C$$
Verificación por Derivación:
$$\frac{d}{dx}\left[ 3\arcsin(x) - (1 - x^2)^{1/2} + C \right] = \frac{3}{\sqrt{1 - x^2}} - \frac{1}{2}(1 - x^2)^{-1/2}(-2x) = \frac{3 + x}{\sqrt{1 - x^2}} \quad \checkmark$$
Ejercicio 2: Fracción Racional Cuadrática Inmediata Taller XI - Ej. 2
$$\int \frac{2x - 7}{x^2 + 9}\,dx$$
Paso 1: Separación en parte logarítmica y parte arco tangente:
$$\int \frac{2x - 7}{x^2 + 9}\,dx = \int \frac{2x}{x^2 + 9}\,dx - 7\int \frac{dx}{x^2 + 3^2}$$
Paso 2: Integración de cada componente:
- En la primera: la derivada de $x^2 + 9$ es $2x$, por ende genera $\ln(x^2 + 9)$.
- En la segunda: aplicamos la regla canónica con $a = 3$: $$7\int \frac{dx}{x^2 + 3^2} = 7 \cdot \frac{1}{3}\arctan\left(\frac{x}{3}\right) = \frac{7}{3}\arctan\left(\frac{x}{3}\right)$$
Paso 3: Expresión analítica final:
$$\ln(x^2 + 9) - \frac{7}{3}\arctan\left(\frac{x}{3}\right) + C$$
Verificación por Derivación:
$$\frac{d}{dx}\left[ \ln(x^2 + 9) - \frac{7}{3}\arctan(x/3) \right] = \frac{2x}{x^2 + 9} - \frac{7}{3} \cdot \frac{1/3}{1 + (x/3)^2} = \frac{2x - 7}{x^2 + 9} \quad \checkmark$$
Ejercicio 3: Exponencial Cuártica y Cambio de Variable Taller XI - Ej. 4
$$\int \frac{2e^{2x}}{1 + e^{4x}}\,dx$$
Paso 1: Identificación de la potencia compuesta:
Observamos que $e^{4x} = (e^{2x})^2$. Sea la sustitución auxiliar $u = e^{2x}$.
Diferenciando: $du = 2e^{2x}\,dx$.
Paso 2: Sustitución directa en la forma arco tangente:
$$\int \frac{2e^{2x}}{1 + (e^{2x})^2}\,dx = \int \frac{du}{1 + u^2} = \arctan(u) + C$$
Paso 3: Retorno a la variable independiente:
$$\arctan(e^{2x}) + C$$
Verificación por Derivación:
$$\frac{d}{dx}\left[ \arctan(e^{2x}) \right] = \frac{1}{1 + (e^{2x})^2} \cdot \frac{d}{dx}(e^{2x}) = \frac{2e^{2x}}{1 + e^{4x}} \quad \checkmark$$
Ejercicio 4: Función Trigonométrica Circular bajo Radical Taller XI - Ej. 5
$$\int \frac{\sec^2 x}{\sqrt{1 - 4\tan^2 x}}\,dx$$
Paso 1: Factorización del radicando y sustitución:
Escribimos $4\tan^2 x = (2\tan x)^2$.
Sea $u = 2\tan x \implies du = 2\sec^2 x\,dx \implies \sec^2 x\,dx = \frac{du}{2}$.
Paso 2: Integración en la variable auxiliar:
$$\int \frac{\frac{du}{2}}{\sqrt{1 - u^2}} = \frac{1}{2}\int \frac{du}{\sqrt{1 - u^2}} = \frac{1}{2}\arcsin(u) + C$$
Paso 3: Solución analítica final:
$$\frac{1}{2}\arcsin(2\tan x) + C$$
